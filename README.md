# Cadastro-de-Gest-o
 Sistema de Gestão Patrimonial desenvolvido para a Sociedade Filarmônica Euterpe Japaratubense (SFEJ), com funcionalidades de cadastro e controle de instrumentos musicais, materiais, termos de responsabilidade e devolução, fichas de músicos e relatórios administrativos.dados guardado no firebase. O USO DA LOGOMARCA FOI AUTORIZADO PELA INSTITUIÇÃO.
